# 三国杀1v1游戏设计与开发文档

## 1. 游戏概述

### 1.1 游戏目标

实现一个简化的三国杀1v1对战游戏，玩家通过选择武将、使用手牌、发动技能，最终击败对手。

### 1.2 游戏模式

1v1对战模式，双方各选择一名武将进行对战。

## 2. 游戏规则

### 2.1 胜利条件

将对方武将的体力值降为0。

### 2.2 游戏流程

1. **武将选择阶段**：双方玩家从魏蜀吴各4名武将中选择一名武将。
2. **准备阶段**：
    - 确定先手玩家。
    - 双方武将获得初始体力值（通常为武将体力上限）。
    - 双方玩家摸取初始手牌（通常为4张）。
3. **回合阶段**：
    - **判定阶段**：若有延时锦囊，在此阶段进行判定。
    - **摸牌阶段**：当前玩家摸取2张牌。
    - **出牌阶段**：当前玩家可以使用任意数量的牌，发动武将技能。
    - **弃牌阶段**：当前玩家手牌数超过体力上限时，需要弃置多余手牌。
4. **结束阶段**：回合结束，轮到下一位玩家。

### 2.3 牌堆构成

- **基本牌**：杀、闪、桃
- **锦囊牌**：过河拆桥、顺手牵羊、无中生有、决斗、南蛮入侵、万箭齐发
- **装备牌**：武器、防具、坐骑

## 3. 武将设计

### 3.1 武将选择

魏、蜀、吴各选择4名武将，共12名武将。

- **魏国**：曹操、司马懿、夏侯惇、张辽
- **蜀国**：刘备、关羽、张飞、诸葛亮
- **吴国**：孙权、周瑜、甘宁、吕蒙

### 3.2 武将技能（简化）

每个武将设计1-2个简化技能，以体现武将特色。

- **曹操**：
    - 奸雄：当你受到伤害后，你可以获得对你造成伤害的牌。
- **司马懿**：
    - 反馈：当你受到伤害后，你可以获得伤害来源的一张手牌或装备牌。
- **夏侯惇**：
    - 刚烈：当你受到1点伤害后，你可以判定，若结果不为红桃，则伤害来源选择弃置2张手牌或受到1点伤害。
- **张辽**：
    - 突袭：摸牌阶段，你可以放弃摸牌，改为从至多两名其他角色的手牌中各抽取一张牌。

- **刘备**：
    - 仁德：出牌阶段，你可以将任意数量的手牌交给一名其他角色，若你给出的牌达到2张或更多，你回复1点体力。
- **关羽**：
    - 武圣：你可以将任意一张红色牌当【杀】使用或打出。
- **张飞**：
    - 咆哮：出牌阶段，你可以使用任意数量的【杀】。
- **诸葛亮**：
    - 观星：回合开始阶段，你可以观看牌堆顶的X张牌（X为存活角色数），然后将其以任意顺序放回牌堆顶或牌堆底。

- **孙权**：
    - 制衡：出牌阶段限一次，你可以弃置任意数量的牌，然后摸取等量的牌。
- **周瑜**：
    - 英姿：摸牌阶段，你可以多摸一张牌。
    - 反间：出牌阶段限一次，你可以令一名其他角色选择一种花色，然后亮出你一张手牌，若此牌不为该花色，则其受到1点伤害，然后其获得此牌。
- **甘宁**：
    - 奇袭：出牌阶段，你可以将一张黑色牌当【过河拆桥】使用。
- **吕蒙**：
    - 克己：若你没有使用或打出过【杀】，你可以跳过弃牌阶段。

## 4. 技术选型

- **编程语言**：Python

## 5. 项目结构

```
sanguosha-1/
├── app/                    # 核心应用代码
│   ├── __init__.py
│   ├── run_game.py        # 完整游戏启动脚本
│   ├── game.py            # 游戏主逻辑类
│   ├── player.py          # 玩家类
│   ├── card.py            # 卡牌基类和具体卡牌实现
│   ├── character.py       # 武将基类和具体武将实现
│   ├── character_factory.py # 武将工厂类
│   ├── deck.py            # 牌堆管理类
│   └── game_engine.py     # 游戏引擎（旧版）
├── test_game.py           # 测试脚本（快速开始）
├── requirements.txt       # 项目依赖
└── README.md             # 项目说明文档
```

### 核心模块说明
- **Card**：牌的基类，包含花色、点数、类型等属性
- **Character**：武将基类，包含体力、技能等属性
- **Player**：玩家类，包含手牌、装备区、判定区等属性
- **Game**：游戏主逻辑类，负责游戏流程控制、回合管理
- **CharacterFactory**：武将工厂类，负责武将创建和管理
- **Deck**：牌堆管理类，负责洗牌、发牌等操作

## 8. 项目概述

### 项目目标
构建一个命令行版的三国杀游戏系统，支持玩家之间的对战，为后续AI对战和图形界面开发奠定基础。

### 功能概述
- 游戏逻辑：完整实现三国杀核心玩法，包括回合流程、卡牌使用、技能发动等
- 武将系统：支持13名武将选择，包含魏、蜀、吴三国武将
- 卡牌系统：实现基本牌（杀、闪、桃）和部分锦囊牌（过河拆桥、顺手牵羊）
- 技能系统：支持咆哮、克己、英姿等武将技能
- 游戏管理：自动检测游戏结束条件（血量≤0或牌堆为空）

### 主要技术栈
- 编程语言：Python 3.x
- 核心模块：纯Python实现，无外部依赖
- 架构：面向对象设计，模块化架构
- 测试：单元测试和集成测试支持

## 9. 运行说明

### 命令行运行
游戏提供两个运行脚本：

1. **完整游戏模式**（支持武将选择）：
```bash
python app/run_game.py
```

2. **测试模式**（快速开始曹操vs刘备对战）：
```bash
python test_game.py
```

### 游戏操作
1. 启动游戏后，两名玩家分别从13名武将中选择（完整模式）
2. 游戏按照三国杀规则进行，包含判定、摸牌、出牌、弃牌阶段
3. 支持基本牌（杀、闪、桃）和部分锦囊牌的使用
4. 支持武将技能：咆哮（张飞）、克己（吕蒙）、英姿（周瑜）
5. 使用Ctrl+C可以中断游戏
