# 三国杀1v1游戏设计与开发文档

## 1. 项目概述

### 1.1 项目背景

三国杀是一款非常受欢迎的桌面卡牌游戏，结合了中国三国时期的历史背景和策略性玩法。本项目旨在实现一个简化的三国杀1v1对战游戏，让玩家能够通过命令行界面体验游戏的核心玩法。

### 1.2 项目目标

构建一个命令行版的三国杀游戏系统，支持玩家之间的对战，为后续AI对战和图形界面开发奠定基础。通过该项目实践面向对象编程、游戏逻辑设计和软件工程方法。

### 1.3 功能概述

- 游戏逻辑：完整实现三国杀核心玩法，包括回合流程、卡牌使用、技能发动等
- 武将系统：支持多种武将选择，包含魏、蜀、吴三国武将
- 卡牌系统：实现基本牌（杀、闪、桃）和部分锦囊牌
- 技能系统：支持多种武将技能
- 游戏管理：自动检测游戏结束条件

## 3. 游戏设计

### 3.1 游戏核心机制

游戏的核心机制包括以下几个部分：

- **初始化游戏**：设置玩家、卡组和初始状态。
- **发牌与洗牌**：实现卡牌的发牌和洗牌功能。
- **回合制出牌**：玩家依次进行出牌，攻击对手。
- **战斗计算**：根据出牌情况计算生命值变化。
- **胜负判断**：判断游戏的胜负条件，结束游戏。

### 3.2 游戏规则

- **牌型定义**：每副卡牌包含攻击牌、防御牌和法术牌。每张牌有自己的效果和属性。
- **游戏开始**：玩家选择角色并准备卡组，然后发牌。
- **出牌规则**：每个玩家在自己的回合中可以出一张牌（攻击、防御或法术），并根据对方的状态进行相应操作。
- **胜负规则**：当任意一名玩家的生命值降至零时，游戏结束，另一方获胜。

### 3.3 角色与资源

游戏中的角色与资源是玩家行动的基础。

**角色**：
- 玩家：参与游戏的角色，拥有生命值和手牌。

**资源**：
- 牌组：包含多张不同功能的卡牌。
- 手牌：玩家当前手中的卡牌。
