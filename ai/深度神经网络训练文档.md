# 三国杀AI深度神经网络训练文档

## 1. 概述

本文档详细描述了三国杀AI系统中使用的深度神经网络架构，包括策略网络（Policy Network）和价值网络（Value Network）的设计理念、结构配置以及训练方案。

## 2. 网络架构总览

### 2.1 整体架构设计
- **算法框架**: PPO (Proximal Policy Optimization)
- **网络类型**: Actor-Critic架构
- **输入处理**: 多模态状态编码器
- **输出**: 动作概率分布 + 状态价值估计

### 2.2 网络组件
1. **状态编码器** (State Encoder)
2. **策略网络** (Policy Network / Actor)
3. **价值网络** (Value Network / Critic)
4. **注意力机制** (Attention Mechanism)

## 3. 详细网络结构

### 3.1 状态编码器 (State Encoder)

#### 3.1.1 输入维度分析
```
游戏状态输入维度:
- 玩家状态: 4玩家 × 20维 = 80维
  - 血量: 1维
  - 手牌数: 1维
  - 装备状态: 4维 (武器、防具、坐骑、宝物)
  - 技能状态: 8维
  - 距离信息: 3维
  - 其他状态: 3维

- 场上卡牌状态: 最大200张卡牌 × 10维 = 2000维
  - 卡牌类型: 3维 (基本牌、锦囊、装备)
  - 卡牌花色: 4维
  - 卡牌点数: 1维
  - 位置信息: 2维

- 历史动作: 最近10步 × 50维 = 500维

总输入维度: 2580维
```

#### 3.1.2 编码器结构
```
Layer 1: 输入层
- 输入维度: 2580
- 输出维度: 1024
- 激活函数: ReLU
- 作用: 初步特征提取和降维

Layer 2: 特征提取层
- 输入维度: 1024
- 输出维度: 512
- 激活函数: ReLU
- Dropout: 0.2
- 作用: 深层特征提取，防止过拟合

Layer 3: 表示学习层
- 输入维度: 512
- 输出维度: 256
- 激活函数: ReLU
- 作用: 学习高级抽象表示
```

**设计理念**:
- **逐层降维**: 从2580→1024→512→256，逐步提取更抽象的特征
- **ReLU激活**: 解决梯度消失问题，加速训练
- **Dropout**: 防止过拟合，提高泛化能力

### 3.2 注意力机制 (Attention Mechanism)

#### 3.2.1 多头注意力结构
```
Multi-Head Attention:
- 输入维度: 256
- 注意力头数: 8
- 每头维度: 32 (256/8)
- 输出维度: 256

Query/Key/Value 投影:
- 线性层: 256 → 256
- 分割为8个头: 每头32维

注意力计算:
- Scaled Dot-Product Attention
- 温度参数: sqrt(32) ≈ 5.66
```

**设计理念**:
- **多头机制**: 捕捉不同类型的关系（玩家间、卡牌间、技能间）
- **自注意力**: 让模型关注状态中的关键信息
- **位置编码**: 保持序列信息的重要性

### 3.3 策略网络 (Policy Network)

#### 3.3.1 网络结构
```
Layer 1: 注意力输出处理
- 输入维度: 256
- 输出维度: 512
- 激活函数: ReLU
- 作用: 扩展特征维度，增强表达能力

Layer 2: 策略特征层
- 输入维度: 512
- 输出维度: 256
- 激活函数: ReLU
- Dropout: 0.1
- 作用: 学习动作相关特征

Layer 3: 动作分支层
- 输入维度: 256
- 输出维度: 128
- 激活函数: ReLU
- 作用: 为不同动作类型准备特征

Layer 4: 输出层
- 输入维度: 128
- 输出维度: 动作空间大小 (约500-1000维)
- 激活函数: Softmax
- 作用: 输出动作概率分布
```

**设计理念**:
- **渐进式特征学习**: 256→512→256→128，先扩展后收缩
- **动作空间适配**: 最终输出维度匹配游戏动作空间
- **概率输出**: Softmax确保输出为有效概率分布

### 3.4 价值网络 (Value Network)

#### 3.4.1 网络结构
```
Layer 1: 状态价值特征
- 输入维度: 256 (来自注意力层)
- 输出维度: 256
- 激活函数: ReLU
- 作用: 学习状态价值相关特征

Layer 2: 价值评估层
- 输入维度: 256
- 输出维度: 128
- 激活函数: ReLU
- Dropout: 0.1
- 作用: 深层价值特征提取

Layer 3: 价值输出层
- 输入维度: 128
- 输出维度: 1
- 激活函数: 无 (线性输出)
- 作用: 输出状态价值估计
```

**设计理念**:
- **共享特征**: 与策略网络共享注意力层输出
- **价值专用**: 独立的价值评估分支
- **线性输出**: 价值可以为任意实数

## 5. 网络设计理念详解

### 5.1 为什么选择这些层数和神经元数量

#### 5.1.1 输入编码层 (2580→1024→512→256)
- **2580维输入**: 完整捕捉游戏状态信息
- **1024维第一层**: 初步降维，保留主要信息
- **512维第二层**: 进一步抽象，去除冗余
- **256维输出**: 平衡表达能力和计算效率

#### 5.1.2 注意力机制 (8头×32维)
- **8个注意力头**: 捕捉多种关系类型
- **32维每头**: 足够的表达能力，避免过度复杂

#### 5.1.3 策略网络 (256→512→256→128→动作空间)
- **先扩展后收缩**: 增强特征表达后聚焦决策
- **128维决策层**: 平衡决策复杂度和计算效率

#### 5.1.4 价值网络 (256→256→128→1)
- **保持维度**: 充分利用共享特征
- **逐步收缩**: 聚焦到单一价值输出

### 5.2 模块设计原理

#### 5.2.1 共享编码器
- **减少参数**: 避免重复学习相同特征
- **一致性**: 确保策略和价值基于相同状态理解

#### 5.2.2 注意力机制
- **关键信息聚焦**: 在复杂状态中找到关键决策因素
- **动态权重**: 根据当前情况调整关注点

#### 5.2.3 分离的输出头
- **专业化**: 策略和价值有不同的学习目标
- **稳定性**: 避免两个任务相互干扰

## 6. 训练策略

### 6.1 课程学习
```
阶段1: 基础规则学习 (0-100k步)
- 学习率: 3e-4
- 对手: 随机策略
- 重点: 合法动作选择

阶段2: 策略优化 (100k-500k步)
- 学习率: 2e-4
- 对手: 混合策略 (50%随机 + 50%历史最佳)
- 重点: 基本策略学习

阶段3: 高级对抗 (500k-1000k步)
- 学习率: 1e-4
- 对手: 自对弈
- 重点: 高级策略和反制
```

### 6.2 数据增强
- **状态随机化**: 随机调整非关键状态信息
- **动作掩码**: 确保只选择合法动作
- **经验回放**: 重要局面的重复学习

### 6.3 正则化技术
- **Dropout**: 防止过拟合
- **权重衰减**: 控制模型复杂度
- **梯度裁剪**: 防止梯度爆炸
- **早停**: 避免过训练

## 7. 性能监控

### 7.1 训练指标
- **策略损失**: 监控策略学习进度
- **价值损失**: 监控价值估计准确性
- **熵值**: 监控策略多样性
- **KL散度**: 监控策略更新幅度

### 7.2 游戏指标
- **胜率**: 对抗不同对手的胜率
- **平均回合数**: 游戏长度指标
- **动作合法率**: 合法动作选择比例
- **技能使用率**: 各技能的使用频率

## 8. 模型部署

### 8.1 模型压缩
- **权重量化**: 降低模型大小
- **知识蒸馏**: 训练更小的学生模型
- **剪枝**: 移除不重要的连接

### 8.2 推理优化
- **批处理**: 并行处理多个状态
- **缓存**: 缓存常见状态的计算结果
- **近似**: 使用近似算法加速推理

本网络架构通过精心设计的层次结构和模块化组件，能够有效处理三国杀游戏的复杂状态空间和动作空间。每个模块的神经元数量都经过仔细考虑，平衡了表达能力、计算效率和训练稳定性。通过持续的训练和优化，该网络能够学习到高水平的三国杀游戏策略。
