# 三国杀1v1游戏设计与开发文档

## 1. 游戏概述

### 1.1 游戏目标

实现一个简化的三国杀1v1对战游戏，玩家通过选择武将、使用手牌、发动技能，最终击败对手。

### 1.2 游戏模式

1v1对战模式，双方各选择一名武将进行对战。

## 2. 游戏规则

### 2.1 胜利条件

将对方武将的体力值降为0。

### 2.2 游戏流程

1. **武将选择阶段**：双方玩家从魏蜀吴各4名武将中选择一名武将。
2. **准备阶段**：
    - 确定先手玩家。
    - 双方武将获得初始体力值（通常为武将体力上限）。
    - 双方玩家摸取初始手牌（通常为4张）。
3. **回合阶段**：
    - **判定阶段**：若有延时锦囊，在此阶段进行判定。
    - **摸牌阶段**：当前玩家摸取2张牌。
    - **出牌阶段**：当前玩家可以使用任意数量的牌，发动武将技能。
    - **弃牌阶段**：当前玩家手牌数超过体力上限时，需要弃置多余手牌。
4. **结束阶段**：回合结束，轮到下一位玩家。

### 2.3 牌堆构成

- **基本牌**：杀、闪、桃
- **锦囊牌**：过河拆桥、顺手牵羊、无中生有、决斗、南蛮入侵、万箭齐发
- **装备牌**：武器、防具、坐骑

## 3. 武将设计

### 3.1 武将选择

魏、蜀、吴各选择4名武将，共12名武将。

- **魏国**：曹操、司马懿、夏侯惇、张辽
- **蜀国**：刘备、关羽、张飞、诸葛亮
- **吴国**：孙权、周瑜、甘宁、吕蒙

### 3.2 武将技能（简化）

每个武将设计1-2个简化技能，以体现武将特色。

- **曹操**：
    - 奸雄：当你受到伤害后，你可以获得对你造成伤害的牌。
- **司马懿**：
    - 反馈：当你受到伤害后，你可以获得伤害来源的一张手牌或装备牌。
- **夏侯惇**：
    - 刚烈：当你受到1点伤害后，你可以判定，若结果不为红桃，则伤害来源选择弃置2张手牌或受到1点伤害。
- **张辽**：
    - 突袭：摸牌阶段，你可以放弃摸牌，改为从至多两名其他角色的手牌中各抽取一张牌。

- **刘备**：
    - 仁德：出牌阶段，你可以将任意数量的手牌交给一名其他角色，若你给出的牌达到2张或更多，你回复1点体力。
- **关羽**：
    - 武圣：你可以将任意一张红色牌当【杀】使用或打出。
- **张飞**：
    - 咆哮：出牌阶段，你可以使用任意数量的【杀】。
- **诸葛亮**：
    - 观星：回合开始阶段，你可以观看牌堆顶的X张牌（X为存活角色数），然后将其以任意顺序放回牌堆顶或牌堆底。

- **孙权**：
    - 制衡：出牌阶段限一次，你可以弃置任意数量的牌，然后摸取等量的牌。
- **周瑜**：
    - 英姿：摸牌阶段，你可以多摸一张牌。
    - 反间：出牌阶段限一次，你可以令一名其他角色选择一种花色，然后亮出你一张手牌，若此牌不为该花色，则其受到1点伤害，然后其获得此牌。
- **甘宁**：
    - 奇袭：出牌阶段，你可以将一张黑色牌当【过河拆桥】使用。
- **吕蒙**：
    - 克己：若你没有使用或打出过【杀】，你可以跳过弃牌阶段。

## 4. 技术选型

- **编程语言**：Python

## 5. 模块设计

- **Card**：牌的基类，包含花色、点数、类型等属性。
- **Character**：武将基类，包含体力、技能等属性。
- **Player**：玩家类，包含手牌、装备区、判定区等属性，以及操作方法。
- **Game**：游戏主逻辑类，负责游戏流程控制、回合管理、事件处理等。
- **UI**：用户界面模块（初期可简化）。

## 6. 开发计划

1. **第一阶段：核心逻辑实现**
    - 实现牌的定义和基本操作。
    - 实现武将的定义和技能。
    - 实现玩家的基本操作（摸牌、出牌、弃牌）。
    - 实现游戏主循环和回合流程。
    - 实现简单的1v1对战逻辑。
2. **第二阶段：武将技能完善**
    - 逐步完善12名武将的技能实现。
    - 确保技能效果符合设计。
3. **第三阶段：用户界面**
    - 实现命令行界面或简单的图形界面。
    - 展示玩家手牌、武将信息、游戏日志等。
4. **第四阶段：测试与优化**
    - 进行功能测试和bug修复。
    - 优化游戏体验和性能。
    - 实现自动化测试脚本，确保技能正确性。

## 8. 项目概述

### 项目目标
构建一个支持三国杀统帅模式的游戏系统，支持玩家之间的对战以及与AI的对战。

### 功能概述
- 玩家管理：支持玩家注册、登录、匹配。
- 游戏逻辑：实现三国杀核心玩法，包括出牌、响应、结算等。
- AI对战：提供智能AI对手，支持多种难度。

### 主要技术栈
- 后端：Python（Flask/Django）
- 前端：React/Vue.js
- 数据库：MySQL/SQLite
- 部署：Docker/Kubernetes

## 9. 运行说明

### 命令行运行
```bash
python main.py
```

### 游戏操作
1. 启动游戏后，两名玩家分别选择武将
2. 游戏按照三国杀规则进行，包含判定、摸牌、出牌、弃牌阶段
3. 支持武将技能使用（部分技能已实现）
4. 使用Ctrl+C可以中断游戏
