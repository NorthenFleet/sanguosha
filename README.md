## 项目概述

### 项目目标
构建一个支持三国杀统帅模式的游戏系统，支持玩家之间的对战以及与AI的对战。

### 功能概述
- 玩家管理：支持玩家注册、登录、匹配。
- 游戏逻辑：实现三国杀核心玩法，包括出牌、响应、结算等。
- AI对战：提供智能AI对手，支持多种难度。

### 主要技术栈
- 后端：Python（Flask/Django）
- 前端：React/Vue.js
- 数据库：MySQL/SQLite
- 部署：Docker/Kubernetes

## 运行说明

### 命令行运行
```bash
python main.py
```

### 游戏操作
1. 启动游戏后，两名玩家分别选择武将
2. 游戏按照三国杀规则进行，包含判定、摸牌、出牌、弃牌阶段
3. 支持武将技能使用（部分技能已实现）
4. 使用Ctrl+C可以中断游戏

## 需求分析

### 功能需求
- 玩家可以选择武将并进行对战。
- 支持单人模式（与AI对战）和多人模式（玩家对战）。
- 游戏状态实时更新并展示。

### 非功能需求
- 系统需支持高并发，保证流畅的游戏体验。
- 界面需简洁直观，易于操作。
